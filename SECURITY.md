# Security

OMP Deck controls local coding agents and must not be exposed to an untrusted network.

Run OMP Deck on `127.0.0.1` and use Tailscale Serve for authenticated HTTPS access from another device. Direct internet exposure is unsupported.

## Reporting a vulnerability

When this repository is public, use **Security → Report a vulnerability** on GitHub. That sends the report privately to this repository's maintainer; it does not create a public issue or report the project to GitHub.

Do not include real credentials or private session transcripts.
